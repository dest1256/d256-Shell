# Security

d256 Shell stores server passwords, so please report vulnerabilities **privately**:
use the *Security → Report a vulnerability* tab of this repository, not public issues.

Include the version, OS, steps to reproduce and the impact. Do not attach real passwords, keys or the contents of the `data` folder.

What counts as a vulnerability: leaking passwords or keys (logs, command line, environment), bypassing the host key check,
running commands on the server without a user action, writing or deleting files outside the requested path.
